# 安装与使用

Vimflow 面向桌面版 Obsidian，要求 Obsidian 1.5.0 或更新版本。

## 安装

1. 从 [Releases](https://github.com/Async23/obsidian-vimflow/releases) 下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 在仓库配置目录内创建 `plugins/vimflow/`，将三个文件放入该目录。默认位置是 `<vault>/.obsidian/plugins/vimflow/`。
3. 重新加载 Obsidian，在“设置 → 第三方插件”中启用 Vimflow。
4. 如有其他接管 `j/k/f` 的全局导航插件，先停用它们，再启用 Vimflow，以免同一按键触发多个动作。

也可以通过 BRAT 添加 `Async23/obsidian-vimflow`。Vimflow 尚未加入 Obsidian 官方社区插件目录。

## 导航和输入

普通模式下，按键用于导航。点击编辑区域或输入框，或者按 `i`，进入输入模式；按 `Esc` 退出输入，回到导航。弹窗、菜单、搜索框由 Obsidian 自己处理。

编辑视图中的 `j/k/h/l` 滚动视口，光标位置保持不变。需要编辑文本时，按 `i` 或点击编辑区域。使用 Obsidian 内置 Vim 编辑时，编辑区域仍由其自身处理；回到 Vimflow 导航后，方向键控制视图。

| 序号 | 按键                  | 动作                                           |
| ---- | --------------------- | ---------------------------------------------- |
| 1    | `j` / `k`             | 向下 / 向上滚动，长按持续移动                  |
| 2    | `h` / `l`             | 向左 / 向右滚动                                |
| 3    | `gg` / `G`            | 到顶部 / 底部                                  |
| 4    | `d` / `u`             | 下滚 / 上滚半页                                |
| 5    | `PageDown` / `PageUp` | 下滚 / 上滚约一屏                              |
| 6    | `f`                   | 显示可见链接、按钮、标签页及侧栏项目的定位字母 |
| 7    | `F`                   | 显示定位字母，在新标签页打开所选内部笔记链接   |
| 8    | `o` / `O`             | 搜索笔记，在当前 / 新标签页打开                |
| 9    | `J` / `K`             | 当前分组的上一个 / 下一个标签页                |
| 10   | `t` / `x`             | 新建 / 关闭标签页                              |
| 11   | `i` / `Esc`           | 进入输入 / 回到导航                            |
| 12   | `/`                   | 打开当前笔记的内置查找                         |
| 13   | `?`                   | 显示快捷键                                     |

定位时依次输入提示字母；`Backspace` 回退一个字符，`Esc` 取消。提示会在滚动、改变窗口大小或点击后清除，避免标签与目标错位。

默认滚动当前活动笔记。点击另一个可滚动区域后，方向键控制该区域；到达边界时停住。切换标签页后重新使用活动视图。

## 滚动设置

“设置 → Vimflow”中可以调整连续滚动速度、短按距离、定位字符和状态栏模式指示。

连续滚动速度按“像素 / 秒”计算。短按会完成设定的最小距离，连续快速短按会累加距离；长按移动超过该距离后，松键立即停止。切到其他窗口、按系统组合键、滚动鼠标滚轮或卸载插件都会停止动画。

## 支持范围

- 支持 Obsidian 主窗口和独立窗口中的 DOM 界面。
- 定位提示覆盖当前窗口的可见目标。
- 嵌入网页的跨域 iframe、Web viewer 内部页面和 Canvas 内部导航暂未适配。
- 首版提供 `gg`，暂未实现数字次数前缀、自定义按键映射、宏和文本编辑命令。
- 插件不发起网络请求，不采集使用数据。设置通过 Obsidian 插件数据接口保存在当前仓库。
