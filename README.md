# Vimflow

为 Obsidian 提供 Vim 风格键盘导航。长按 `j/k` 时按画面刷新节奏连续滚动，松键停止；通过字母提示打开链接和操作工作区。

支持笔记阅读、编辑视图滚动、侧栏及独立窗口。输入框与弹窗保留原有按键行为。

启用后按 `Esc` 进入导航，长按 `j/k` 滚动，按 `f` 显示定位字母；按 `i` 进入编辑。
